# Pi Agent Book 中文版

Pi Agent SDK 源码阅读笔记。本站收录 [Pi Agent Book](https://www.dgzhuya.com/) 的中文原文（canonical），英文与越南语译本见侧边栏导航。

## 阅读建议

- 按章节顺序阅读：第 1 章先建立动机与全局视角，第 2 章理清三层架构，后续章节按需查阅。
- 每章末尾给出对应的 [pi.dev](https://pi.dev/docs/latest) 官方文档链接，可与原文交叉验证。
- 代码示例可直接复制运行；前置环境见 [Pi 官方文档](https://pi.dev/docs/latest/quickstart)。
