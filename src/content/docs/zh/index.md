Pi Agent SDK 源码阅读笔记。[Pi Agent Book](https://www.dgzhuya.com/) 的中文原著是唯一权威版本。

## 阅读方式

- 按顺序阅读各章。第 1 章讲述动机和总体视图；第 2 章讲解三层架构；后面的章节是参考资料，可随时查阅。
- 每章都链接到官方 [pi.dev](https://pi.dev/docs/latest) 对应页面以供核实。
- 代码样例可运行。环境准备说明：[Pi quickstart](https://pi.dev/docs/latest/quickstart)。
