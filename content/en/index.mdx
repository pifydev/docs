Source-reading notes for the [Pi Agent SDK](https://github.com/earendil-works/pi), published in English and Vietnamese. The numbered chapters retain the structure of the original Pi Agent Book, but current upstream code and documentation take precedence when the implementation has changed.

<Callout type="info">
New here? Start with the [Quickstart](quickstart.md) to make a streaming model call. Go straight to the numbered chapters for the architecture and source walkthroughs.
</Callout>

## How to read

- **New to Pi:** [Quickstart](quickstart.md) first, then chapters in order.
- **Reading for the architecture:** chapters 1 through 3 establish the three-layer model and the agent loop. Read the remaining chapters as focused explanations of models, tools, messages, events, context, compaction, and sessions.
- **Building on Pi:** the [How-to Guides](how-to/add-custom-tool.md) are short task-oriented recipes.
- **Looking up an API or env var:** the [Reference](reference/api.md) is structured for lookup, not reading.

Technical claims are checked against a pinned revision of the official Pi repository. Code identifiers and package names follow the current `@earendil-works/pi-*` packages.

## Sections

- [**Quickstart**](quickstart.md) - make your first streaming model call.
- [**Glossary**](glossary.md) - the terms Pi uses for itself, and how this book uses them.
- [**How-to Guides**](how-to/add-custom-tool.md) - 5 task-oriented recipes: tools, model providers, streaming, sessions, prompts.
- [**Reference**](reference/api.md) - package exports, configuration, and environment variables.
- [**Chapters**](ch01-overview.md) - 10 long-form chapters covering the SDK end to end.
- [**FAQ**](help/faq.md) - common questions about Pi and this book.
- [**Changelog**](changelog.md) - what changed in this site.
