# Pify Agent Book (Tiếng Việt)

Ghi chú đọc source code của [Pi Agent SDK](https://github.com/earendil-works/pi). Bản dịch tiếng Việt của [Pi Agent Book](https://www.dgzhuya.com/), với tiếng Trung là bản canonical. Bản tiếng Việt theo cấu trúc và thứ tự chương của bản gốc.

## Cách đọc

- Đọc theo thứ tự chương. Chương 1 nêu động lực và bức tranh toàn cảnh; Chương 2 giải thích kiến trúc ba lớp; các chương sau là tài liệu tham khảo, có thể tra cứu theo nhu cầu.
- Mỗi chương có liên kết đến trang tương ứng trên [pi.dev](https://pi.dev/docs/latest) để đối chiếu.
- Code mẫu có thể chạy trực tiếp. Hướng dẫn cài đặt: [Pi quickstart](https://pi.dev/docs/latest/quickstart).
