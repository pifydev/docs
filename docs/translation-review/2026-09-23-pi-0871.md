## Review rules

English and Vietnamese were reviewed as one semantic unit. Headings, tables, callouts, links, and code-fence order were compared for every pair. All 434 code fences in each locale were inspected: 328 paired bodies are byte-identical and 106 intentionally localize prose, comments, prompts, or diagram labels while retaining the same identifiers and structure. The count recognizes matching backtick or tilde fences of any length of at least three, including the four-backtick outer example in Chapter 6.

IT/Coding terms, package names, commands, flags, API identifiers, type names, event names, and object keys remain in English. Vietnamese prose may differ in word order when that makes it natural, but it must preserve the English technical claim. `substantive` means a released behavior or contract changed; `pin-only` means only release authority, review date, or a comparison label changed; `verified unchanged` means the pair needed no edit after the source and bilingual review.

Content is deleted only when it is source-proven as wrong or duplicated on the same page. Any such deletion must be named in that page's ledger row; otherwise the preservation manifest remains unchanged.
